# Emerald Beauty

Tu es un expert senior en design web premium, UX/UI, conversion locale et développement d’applications avec Lovable.



Ta mission est de créer un site web complet, moderne, élégant et fonctionnel pour une prothésiste ongulaire.



Je vais joindre plusieurs captures d’écran servant de références visuelles.



Tu dois analyser précisément leur direction artistique :



palette de couleurs ;

typographies ;

espacement ;

formes des boutons ;

style des cartes ;

disposition des photos ;

niveau de sobriété ;

élégance générale ;

ambiance féminine et premium ;

animations ;

organisation des sections ;

expérience mobile.



Ne reproduis pas simplement les captures à l’identique. Inspire-toi de leur univers graphique pour créer un site original, cohérent, professionnel et plus abouti.



1. Objectif principal



Le site doit permettre à une cliente de :



découvrir l’univers de la prothésiste ongulaire ;

consulter les prestations et les tarifs ;

voir les réalisations ;

choisir une prestation ;

sélectionner une date et un créneau disponible ;

renseigner ses coordonnées ;

transmettre éventuellement une inspiration ou une photo ;

confirmer sa demande de rendez-vous ;

recevoir ensuite une confirmation automatisée.



Le site doit inspirer immédiatement :



confiance ;

professionnalisme ;

douceur ;

élégance ;

hygiène ;

qualité ;

expertise ;

proximité.



Le rendu ne doit pas ressembler à un template générique de salon de beauté.



2. Positionnement visuel



Créer une direction artistique féminine, moderne, raffinée et premium, sans être trop chargée.



Éviter :



le rose trop vif ;

l’accumulation de paillettes ;

les polices difficiles à lire ;

les animations excessives ;

les blocs trop volumineux ;

les designs trop enfantins ;

les effets “site Canva” ;

les visuels génériques de banque d’images.



Privilégier :



une mise en page aérée ;

une navigation simple ;

de grandes photos de réalisations ;

des couleurs douces et cohérentes avec les captures ;

des détails élégants ;

des boutons clairement visibles ;

des transitions légères ;

des cartes raffinées ;

une excellente lisibilité sur téléphone.



Le site doit être pensé en priorité pour une utilisation mobile.



3. Structure générale du site



Créer les pages ou sections suivantes.



Page d’accueil



Inclure :



un header élégant ;

le logo ou le nom de la prothésiste ;

une navigation simple ;

un bouton principal “Prendre rendez-vous” ;

une section hero avec une phrase forte ;

une courte présentation ;

une sélection de prestations ;

une galerie de réalisations ;

des témoignages ;

un bloc expliquant le déroulement d’un rendez-vous ;

une section hygiène et qualité ;

un rappel de prise de rendez-vous ;

les coordonnées ;

les réseaux sociaux ;

un footer complet.



Exemple de texte d’accroche :



“Des ongles élégants, soignés et personnalisés selon votre style.”



Ajouter un sous-texte rassurant expliquant que chaque prestation est réalisée avec précision, écoute et attention.



Section présentation



Présenter la prothésiste avec :



une photo ;

son approche ;

son expérience ;

sa spécialité ;

ses valeurs ;

son sens du détail ;

son engagement concernant l’hygiène et la satisfaction cliente.



Le texte doit être chaleureux, humain et professionnel.



Prestations et tarifs



Créer des cartes distinctes pour les principales prestations :



pose complète ;

semi-permanent ;

gainage ;

remplissage ;

dépose ;

nail art ;

réparation d’un ongle ;

prestations pieds ;

suppléments éventuels.



Chaque carte doit pouvoir comporter :



le nom ;

une courte description ;

la durée ;

le prix ;

les options ;

un bouton “Choisir cette prestation”.



Prévoir une architecture facilement modifiable depuis les données du projet.



Ne pas inscrire des tarifs définitifs s’ils ne sont pas fournis. Utiliser des données d’exemple clairement modifiables.



Galerie



Créer une galerie haut de gamme avec :



plusieurs catégories ;

ongles courts ;

ongles longs ;

french ;

couleurs unies ;

nail art ;

poses naturelles ;

avant/après si nécessaire.



Ajouter :



un affichage en grille ;

un système de filtrage ;

une ouverture des photos en grand ;

une navigation fluide ;

un bon recadrage sur mobile.



Prévoir une structure permettant de remplacer facilement les images.



Témoignages



Créer une section avec :



prénom de la cliente ;

note ;

avis ;

type de prestation ;

photo éventuelle de la réalisation.



Utiliser des témoignages temporaires clairement identifiés comme exemples, afin qu’ils puissent être remplacés.



Questions fréquentes



Prévoir notamment :



combien de temps dure une pose ;

comment préparer ses ongles ;

quelle prestation choisir ;

comment fonctionne le remplissage ;

les conditions d’annulation ;

les retards ;

les accompagnants ;

les moyens de paiement ;

les précautions après la prestation ;

les allergies ou problèmes particuliers.



Utiliser des accordéons élégants.



4. Système de prise de rendez-vous



Créer un véritable parcours de réservation en plusieurs étapes.



Étape 1 : choisir une prestation



Afficher :



nom ;

description ;

tarif ;

durée ;

options supplémentaires.



Étape 2 : choisir une date



Créer un calendrier moderne permettant de sélectionner une date.



Les jours complets ou indisponibles doivent être désactivés.



Les jours disponibles doivent être clairement identifiables.



Étape 3 : choisir un horaire



Afficher uniquement les créneaux disponibles pour la date sélectionnée.



Exemples :



09 h 00 ;

10 h 30 ;

13 h 30 ;

15 h 00 ;

17 h 00.



Les horaires doivent être générés à partir des disponibilités reçues depuis une source externe.



Étape 4 : informations de la cliente



Prévoir les champs :



prénom ;

nom ;

téléphone ;

adresse e-mail ;

prestation choisie ;

date ;

heure ;

commentaire ;

préférence particulière ;

lien Instagram facultatif ;

première visite ou cliente existante.



Étape 5 : inspiration



Permettre à la cliente :



d’ajouter une image ;

d’ajouter plusieurs images si nécessaire ;

d’écrire une description ;

d’indiquer la forme souhaitée ;

d’indiquer la longueur ;

d’indiquer les couleurs ;

d’indiquer le type de nail art.



Étape 6 : récapitulatif



Afficher clairement :



prestation ;

options ;

prix estimé ;

durée ;

date ;

heure ;

coordonnées ;

conditions d’annulation.



Ajouter une case obligatoire :



“J’accepte les conditions de réservation et d’annulation.”



Étape 7 : confirmation



Afficher une page de confirmation élégante avec :



résumé du rendez-vous ;

message de remerciement ;

indication qu’une confirmation sera envoyée par e-mail ou SMS ;

bouton Instagram ;

bouton pour revenir à l’accueil.



5. Préparation pour l’automatisation n8n



L’architecture doit être conçue pour que la réservation puisse être connectée à n8n ultérieurement.



Créer une couche de service clairement séparée du design.



Prévoir une variable d’environnement pour le webhook :



VITE_N8N_BOOKING_WEBHOOK_URL



Lors de la validation d’une réservation, envoyer une requête HTTP POST contenant un JSON propre et structuré.



Format attendu :



{

“bookingId”: “identifiant_unique”,

“createdAt”: “date_iso”,

“status”: “pending”,

“customer”: {

“firstName”: “”,

“lastName”: “”,

“email”: “”,

“phone”: “”,

“instagram”: “”,

“customerType”: “new”

},

“service”: {

“id”: “”,

“name”: “”,

“durationMinutes”: 0,

“basePrice”: 0

},

“options”: [

{

“id”: “”,

“name”: “”,

“price”: 0,

“durationMinutes”: 0

}

],

“appointment”: {

“date”: “”,

“startTime”: “”,

“endTime”: “”,

“timezone”: “Europe/Paris”

},

“preferences”: {

“shape”: “”,

“length”: “”,

“colors”: “”,

“designDescription”: “”,

“notes”: “”

},

“inspirationImages”: [],

“estimatedTotal”: 0,

“consent”: true,

“source”: “website”

}



Prévoir également une fonction permettant de récupérer les disponibilités depuis une future URL :



VITE_N8N_AVAILABILITY_WEBHOOK_URL



Cette requête pourra recevoir :



{

“serviceId”: “”,

“month”: “”,

“timezone”: “Europe/Paris”

}



Elle devra retourner une liste de jours et créneaux disponibles.



Créer pour le moment un mode de démonstration avec de fausses disponibilités, mais organiser le code pour pouvoir remplacer facilement ces données par l’appel au webhook n8n.



Ne jamais coder l’URL n8n directement dans les composants.



6. Gestion du planning



Prévoir les règles suivantes dans l’interface :



horaires différents selon les jours ;

jours de repos ;

pauses dans la journée ;

congés ;

créneaux bloqués ;

durée variable selon les prestations ;

temps de pause entre deux clientes ;

réservation impossible dans le passé ;

délai minimum avant réservation ;

nombre maximal de jours réservables à l’avance ;

impossibilité de réserver deux fois le même créneau.



Le front-end doit recalculer l’heure de fin selon la prestation et les options choisies.



7. Paiement ou acompte



Préparer l’interface pour l’ajout ultérieur d’un acompte.



Ne pas connecter un paiement réel pour le moment sauf si une configuration Stripe est fournie.



Ajouter une option désactivée ou simulée permettant plus tard :



le paiement d’un acompte fixe ;

le paiement d’un pourcentage ;

la confirmation du rendez-vous après paiement ;

l’annulation automatique en cas de non-paiement.



Afficher clairement lorsque le prix est une estimation et peut varier selon le nail art ou la complexité demandée.



8. Espace d’administration simplifié



Créer une page d’administration protégée ou une maquette fonctionnelle d’espace administrateur.



Elle doit permettre de visualiser :



les rendez-vous à venir ;

les demandes en attente ;

les réservations confirmées ;

les annulations ;

les créneaux disponibles ;

les jours bloqués ;

les prestations ;

les tarifs ;

les durées ;

les clientes ;

les commentaires ;

les images d’inspiration.



Créer un tableau clair avec des statuts :



en attente ;

confirmé ;

terminé ;

annulé ;

absent.



Prévoir des boutons :



confirmer ;

modifier ;

annuler ;

contacter la cliente ;

bloquer un créneau.



Cette partie doit être préparée pour être reliée plus tard à Supabase, Airtable, Google Calendar, Notion ou une autre base via n8n.



9. Pages légales et règles



Ajouter :



mentions légales ;

politique de confidentialité ;

conditions de réservation ;

politique d’annulation ;

gestion des cookies ;

consentement pour l’utilisation des données ;

consentement facultatif pour recevoir des communications.



Les textes peuvent être provisoires, mais ils doivent être clairement identifiés comme devant être personnalisés avant la mise en ligne.

Optimiser le site pour le référencement local.

Ne pas inventer une ville ni une adresse. Utiliser des variables facilement modifiables.



11. Expérience mobile



Le site sera principalement visité depuis Instagram et un smartphone.



La version mobile doit donc être prioritaire.



Prévoir :



un bouton de réservation toujours accessible ;

une navigation mobile élégante ;

des formulaires faciles à remplir ;

de grands boutons ;

des champs adaptés au clavier mobile ;

des cartes compactes ;

des images rapides à charger ;

un calendrier utilisable au doigt ;

une barre fixe inférieure facultative avec “Réserver”, “Instagram” et “Appeler”.

Le site doit être :



responsive ;

rapide ;

maintenable ;

cohérent ;

sans erreurs visibles ;

13. Contenu et tonalité



Rédiger les textes dans un français naturel, élégant, chaleureux et professionnel.



Éviter les expressions génériques comme :



“Bienvenue dans notre univers” répété partout ;

“Sublimez votre beauté” ;

“Une expérience unique” sans explication ;

les textes trop commerciaux ;

les promesses exagérées.



Le texte doit donner l’impression que la prothésiste s’adresse directement à ses clientes.



14. Images et contenu provisoire



Lorsque les vraies photos ne sont pas encore fournies :

ne pas surcharger avec des images génériques ;

indiquer clairement où remplacer les images ;

préparer les galeries pour recevoir les vraies réalisations.
